# CajitaFeliz — Sistema Web de Caja de Ahorro (Grammer)

**CajitaFeliz** es una aplicación web interna de **Grammer Automotive Puebla S.A. de C.V.** para gestionar la **Caja de Ahorro** del personal: activación/modificación del ahorro, **solicitudes de préstamo**, **retiros** y consulta de estatus e historial. Incluye módulo administrativo para responder solicitudes de forma individual o masiva (Excel), configurar convocatorias y filtrar información histórica.

Repositorio: https://github.com/ElaRCamo/CajitaFeliz

---

## Descripción

El sistema permite a las y los colaboradores:
- **Activar o modificar** el plan de ahorro semanal (con registro de **beneficiarios**).
- **Retirar** el ahorro acumulado (con confirmación por **TAG**).
- **Solicitar préstamos**, recibir **folio** y dar seguimiento.
- Consultar **estatus**, **preguntas frecuentes**, **estatutos** y **mis solicitudes** (historial).

El módulo **Administrador** habilita:
- Responder solicitudes (ahorro, retiros y préstamos).
- **Procesamiento masivo** vía **Excel** (exportar/importar).
- **Convocatorias**: definir fecha/hora de inicio y cierre para recepción de préstamos.
- **Filtros por año** y consultas históricas.

---

## Funciones principales

- 🧾 **Préstamos**: solicitud rápida, folio de turno y seguimiento por estatus.
- 💰 **Caja de Ahorro**: alta/modificación del ahorro, beneficiarios y retiros.
- 📂 **Historial**: sección “Mis Solicitudes” con detalles y edición cuando aplica.
- 📑 **Estatutos** y **FAQ** accesibles desde la interfaz.
- 🛠️ **Administración**: respuesta individual/masiva, reportes en **Excel**, convocatorias y filtros.
